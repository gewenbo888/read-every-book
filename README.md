# AI Has Already Read Every Book · 阅读的未来

A civilization-scale meditation on what reading is for after language models. Five sections — Age of Books, Why AI Changed Everything, Why AI Cannot Replace Real Reading, The Future of Learning, the Civilization Manifesto — built as a single immersive scroll with a WebGL neural galaxy, a token river, and an orbiting cognition diagram.

## Links

- **Live:** [read-every-book.psyverse.fun](https://read-every-book.psyverse.fun)
- **GitHub:** [github.com/gewenbo888/read-every-book](https://github.com/gewenbo888/read-every-book)

## Stack

- Next.js 14 (App Router, `src/app/`)
- React 18 + TypeScript
- Three.js for the WebGL galaxy & particle morph (book lattice → embedding cloud)
- Canvas 2D for the token river
- Framer Motion for scroll reveal choreography
- Tailwind CSS with a custom dark palette (photon / latent / ember / verdant / rose)
- Fonts: Fraunces (display serif), Space Grotesk (body), JetBrains Mono (HUD), Noto Serif SC (中文)
